■推定テクニック値計算ルーチン(無印3風)
r = 0 r += 技威力 * unitcalc.power r += ステータスから基本となる値計算(unit, unitcalc) r = r * 41 / 4096 r = r + unitcalc.magnification if (ランダム計算をする場合) { ; 0以上unitcalc.random_width未満の乱数 r += rand(unitcalc.random_width) } else { r += (unitcalc.random_width / 2) } r += (unitcalc.shoot_power * 必殺技じゃないシュートの4段階の強さ(0～3)) r += ダブルやトリプルによる補正を計算(unitcalc) r += 属性の相性による補正を計算(unit, opponent_unit) if (技の属性 == 選手の属性) { r += 属性一致による補正 } if (unitcalc.limit > 0) { return min(r, unitcalc.limit) } else { return max(r, unitcalc.limit) }
