推定トータルテクニック クリティカル発生率

推定トータルテクニック計算式の詳細について 大きく6段階に分かれているものとして計算。

> 推定トータルテクニック = ( ( 必殺技のパワー + ベースパワー ) * 各種補正 + 化身補正 ) * 体調補正 * クリティカル補正 * 距離補正 * レベル差補正

■必殺技のパワー
必殺技やそれを強化するスキルによる強化。
GOシリーズではほとんどの自力習得技を秘伝書で上書きできてしまうため、この部分は固定化されやすい。

> 必殺技のパワー = (必殺技威力 * 進化補正) * 守備補正 + スキル補正（必殺技強化） + 属性相性（選手と技）

■必殺技威力
必殺技ごとに決まっている基本威力。
とっぱやスライディングのような非必殺技のコマンドも低威力必殺技扱い。

■進化補正
進化系統に関わらず、全ての必殺技は最終進化で1.5倍となる。
対戦が前提であれば1.5固定と考えてOK。

■守備補正
必殺技が守備(ブロック、キャッチ)の場合にのみ有効となる。
1倍、 1.2倍、1.44倍、1.8倍のいずれかの倍率をとる。
必殺技が攻撃(シュート、ドリブル)の場合は対象外。
1.2倍になる確率が最も高い。

■スキル補正（必殺技強化）
必殺技威力を直接強化するスキル
属性の心得、属性強化：+10
属性の雄叫び：+20

■属性相性（選手と技）
一致：+5
不利：-5
他：0

■ベースパワー

> ベーステクニック * 2 / 3 - ( ベーステクニックの2乗 / 1480) + ( ベーステクニック * 40 / 197 ) - (8/17)

■ベーステクニック

> ( メインステータス * 8 + テクニック * 2 ) / 10
コマンド選択時に表示する際には小数点以下を切り捨てるが、トータルテクニック計算時には小数点以下もそのまま扱う。

■各種補正
ベースパワーに対してかかる様々な補正。
各種補正はトータルパワーに対して順番に補正を与えていく。

> 上振れ * スキル補正(トータルテクニック強化) * 失敗判定 * 属性相性（選手と選手）

■上振れ
1.0倍か1.2倍になる。1.2倍になる確率の方が高い。

■スキル補正(トータルテクニック強化)
トータルテクニック全体を強化するスキル(ちょうわざ！、こんしん！)のいずれかを習得し、なおかつ化身必殺技の計算でない場合、1.2倍になる。
上記条件を満たしていない場合は1.0倍。

■失敗判定
1.0倍か0.8倍になる。テクニック値が高いほど0.8倍にはなりにくくなる。
次回作以降の必殺技に存在する難易度は存在せず、必殺技を使用する際はどれだけテクニック値が高くても0.8倍になるケースは発生する。
ただし、化身必殺技使用時は1固定。

■属性相性（選手と選手）
必殺技が守備(ブロック、キャッチ)の場合にのみ有効となる。
属性有利なら1.2倍、不利なら0.8倍。それ以外は1.0倍。
必殺技が攻撃(シュート、ドリブル)の場合には1固定と考えてOK。

■化身補正
コマンドバトルを行っている選手自身が化身を発動させている場合、自身が発動中の化身の現在化身ポイントと化身アタックを合算した値を加算する。
化身を発動させていない場合は0。

■体調補正
GPが0のとき、0.5倍の補正がかかる。
化身発動中は1固定と考えてよく、とりあえず対戦で枯渇することもないので1固定。

■クリティカル補正
1.0倍か2.0倍になる。やくびょうがみ習得者は4.0倍。
2.0倍になる確率は推定で「ラッキー値 / 25 (%)」。

■距離補正
計算対象のコマンドがシュートの場合のみ、シュート実行者からゴールまでの距離を参考にして0.5倍、0.8倍、1.0倍の補正を与える。
ペナルティエリア内かつゴールの前ならだいたい1.0倍。

■レベル差補正
コマンドバトルの相手が自身より高レベルの場合、弱体化する。
対戦ではレベル99同士であることが想定されるため、1固定と考えてOK。
